# Neri Home | El Dokuma Keçi Kılı & Cicim Tekstil

Tekirdağ Saray Küçükyoncalı (Küçükmanika) köyünde 1875 Rumeli göç mirasıyla, kadın dokuma ustalarımızın ahşap el tezgâhlarında %100 doğal keçi kılı ve yün ipliklerle dokunan kırlent, dolay yastık, çanta, heybe ve runner koleksiyonu.

🌐 **Canlı Site:** [https://mserman90.github.io/neri-home-el-dokuma/](https://mserman90.github.io/neri-home-el-dokuma/)

---

## 🧶 Özellikler

- **1875 Sandık Mirası & Motifler:** Su Yolu, Göç Yolları, Eli Belinde, Koçboynuzu, Pıtrak ve Üç Güller motiflerinin hikayelerini içeren interaktif motif sözlüğü.
- **İnteraktif Koltuk & Mekân Önizleme:** Müşterilerin koltuk kumaşı rengini (Krem, Antrasit, Zümrüt Yeşili, Taba) seçerek kırlentlerin duruşunu görebildikleri simülasyon.
- **Doku Büyüteci (Image Magnifier):** Ürün detayında el dokumasının ilmeklerini yakından inceleme imkânı.
- **Sipariş & Ödeme Seçenekleri:** Doğrudan WhatsApp hattı ve kredi kartı/taksitli güvenli ödeme bağlantısı (Shopier/iyzico uyumlu).
- **Açık / Koyu Tema:** Sistem tercihiyle senkronize veya manuel değiştirilebilir sıcak toprak tonları.
- **Usta İmzalı Sertifika & Bakım Rehberi:** Menşe mührü, usta imzası ve doğal lif kullanım kılavuzu.
- **Local Storage Destekli Sepet & Favoriler:** Sunucusuz ortamda bile verileri tarayıcıda güvenle saklayan mimari.

## 🚀 Yerel Kurulum

```bash
# Depoyu klonlayın
git clone https://github.com/mserman90/neri-home-el-dokuma.git
cd neri-home-el-dokuma

# Bağımlılıkları yükleyin
npm install

# Geliştirme sunucusunu başlatın
npm run dev
```
